# TechGear E-Commerce Demonstration

## Run locally
1. Extract this folder.
2. Open the folder in VS Code and run `index.html` with Live Server, or serve the folder using another local static server.
3. Use the top navigation to browse the catalog, cart, About Us and Contact Us pages.

## Features
- Product catalogue with product-name search.
- Add products to the cart.
- Increase/decrease quantities and remove products.
- Cart total and clear-cart control.
- Cart data saved in browser Local Storage.
- Client-side navigation for Catalog, Cart, About Us and Contact Us.

## Technologies
HTML5, CSS3 and vanilla JavaScript.

## Project limitation
This is a frontend demonstration using sample product data. It does not include a backend, real inventory, user accounts, order placement or payment processing.
